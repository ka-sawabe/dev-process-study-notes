# 画面項目定義

---
## <凡例>　各項目の意味
### 画面項目

- 項目ID：項目を一意に識別するID
- 項目名：画面上の名称
- 入力種別：テキスト、ボタン、リンク、ラベル、プルダウンなど
- 入力文字タイプ：全角、半角英数字、数値、記号など
- 桁数：入力可能な最大桁数
- 必須：入力必須かどうか　〇：必須
- 初期値（設定値）：入力項目に表示する初期値
- プレースホルダー：未入力時に表示する入力例や説明文
- 活性／非活性：利用可能条件　**※空は常に活性状態**
- 表示条件：表示条件がある場合のみ記載 **※空は常に表示**
- 説明：項目の用途や役割

## G021 空き枠選択画面
---

### 画面項目定義

|項目ID|項目名|入力種別|入力文字タイプ|桁数|必須|初期値（設定値）|プレースホルダー|活性／非活性|表示条件|説明|
|---|---|---|---|---|---|---|---|---|---|---|
|I0010|生徒名|ラベル|－|－|－|－|－|－||生徒名を表示する。形式：生徒名（姓）+ 全角スペース + 生徒名（名）|
|I0020|担当講師・コース|ラベル|－|－|－|－|－|－||前画面で選択した講師名（姓）+ コースを表示する。形式：{講師名}({コース})|
|I0030|次回予約日時|ラベル|－|－|－|－|－|－|次回の予約がある場合のみ表示|予約日時を表示する。形式：「MM月DD日（月）hh:mm～」|
|I0040|受講回数|ラベル|－|－|－|－|－|－||今月受講した回数を表示する。形式：「0/4回」|
|I0050|レッスン枠カレンダー|バーチカルカレンダーUI|－|－|〇|－|－|次回の予約日時が設定済み or 今月の受講回数 >= 4の場合非活性||担当講師の予定を抽出してカレンダーにレッスン枠を表示する。（ウィークリーのバーチカル形式）<br>予約可能な時間に○、予約不可能な時間に×を表示する。<br>カレンダーからレッスン枠を選択すると、次の予約確認画面に遷移する。|
|I0060|戻る|ボタン|－|－|－|－|－||生徒の場合：非表示、講師・スタッフの場合：表示|講師・生徒選択画面に遷移する。|

#### イベント定義

##### 初期表示時
- 生徒名、担当講師名・コースをラベルに設定する。
  - 利用者が講師・スタッフの場合は、講師・生徒選択画面から受け取る。
  - 利用者が生徒の場合は、ログイン中の生徒情報（生徒名・担当講師・コース）をDBから取得する。 
- 次回の予約日時、当月の受講回数をDBから取得する。ラベルに設定する。
- DBから該当する講師・コースの予定を取得し、レッスン枠カレンダーに設定する。

##### レッスン枠カレンダー選択時
- 予約確認画面へ遷移する。選択した生徒名、講師名、コース、予約日時を次画面へ渡す。（補足参照）

**補足**
次画面への遷移はReact Routerの利用を想定。
useNavigateのstateに値を設定する。

例
```
navigate("/reservation-confirm", {
state: {
    selectedStudent: {
      studentId: 10,
      studentName: "山田 涼介"
    },
    selectedTeacher: {
      teacherId: 1,
      teacherName: "二宮",
      course: "ピアノ"
    },
    selectedLesson: {
        lessonDateTime: "2026-09-01T10:00:00"
    }
  }
});
```
