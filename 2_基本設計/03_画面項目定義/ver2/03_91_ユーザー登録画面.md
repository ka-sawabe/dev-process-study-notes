# 画面項目定義

---
## <凡例>　各項目の意味
### 画面項目

- 項目ID：項目を一意に識別するID
- 項目名：画面上の名称
- 入力種別：テキスト、ボタン、リンク、ラベル、プルダウンなど
- 入力文字タイプ：全角、半角英数字、数値、記号など
- 桁数：入力可能な最大桁数
- 必須：入力必須かどうか　〇：必須
- 初期値（設定値）：入力項目に表示する初期値
- プレースホルダー：未入力時に表示する入力例や説明文
- 活性／非活性：利用可能条件　**※空は常に活性状態**
- 表示条件：表示条件がある場合のみ記載 **※空は常に表示**
- 説明：項目の用途や役割

#### 補足

**利用者区分の表示について**
遷移元の違いによって表示分けをする。
- ☆1[ログイン画面⇒ユーザー登録画面]　で遷移した場合
- ☆2[招待メールのURL⇒利用者区分選択画面⇒ユーザー登録画面]　で遷移した場合

#### イベント定義

##### 初期表示時
- 以下を前画面から受け取って、ラベルに設定する。
  - 遷移元の画面名
  - 利用者区分
- 講師名（姓）・コースドロップダウンリストに設定する。
  - 講師名（姓）および担当コースをDBから取得する。
  - ドロップダウンリストに設定する。

##### 登録内容を確認ボタンを押下時
- ユーザー登録確認画面へ遷移する。
- 以下を次画面に渡す。（補足参照）
  - 遷移元の画面名
  - 利用者区分
  - 氏名（姓・名）、メールアドレス、パスワード、電話番号
  - 講師名・コース（利用者区分が生徒の場合）／選択したすべてのコース（利用者区分が講師の場合） 


#### 補足
#####　ドロップダウンリストの設定値

**担当講師・コース**
講師名（姓）と担当するコースを以下のように表示する
（例）
|行数|設定値|
|---|---|
|1|選択してください|
|2|櫻井（ギター）|
|3|二宮（ギター）|
|4|二宮（ピアノ）|
|5|松本（ボーカル）|

**補足**
次画面への遷移はReact Routerの利用を想定。
useNavigateのstateに値を設定する。

例
**ログイン画面から遷移、利用者区分＝生徒を登録する場合**
```
navigate("/lesson-schedule-confirm", {
state: {
      source : "login",
      user:{
        userCategory: {id: 1,name : "生徒"},
        userFirstName: "山田",
        userLastName: "涼介",
        mail:"test@test.co.jp",
        password:"pass1234",
        telephone:"12345678901",
        selectedTeacher: {
          teacherId: 1,
          teacherName: "山田",
          selectedCourse: { CourseId: 1, CourseName: "ピアノ"} 
        }
      }
   }
});
```
**招待メールのURL⇒利用者区分選択画面から遷移、利用者区分＝講師を登録する場合**
```
navigate("/lesson-schedule-confirm", {
state: {
      source : "invitation",
      user:{
        userCategory: {id: 2,name : "講師"},
        userFirstName: "二宮",
        userLastName: "和也",
        mail:"test@test.co.jp",
        password:"pass1234",
        telephone:"12345678901",
        selectedCourse: [
          {CourseId: 1,CourseName: "ピアノ"},
          {CourseId: 2,CourseName: "ギター"},
          {CourseId: 5,CourseName: "サックス"}
        ]
      }
  }
});
```
