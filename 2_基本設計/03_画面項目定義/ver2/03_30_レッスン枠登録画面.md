# 画面項目定義

---
## <凡例>　各項目の意味
### 画面項目

- 項目ID：項目を一意に識別するID
- 項目名：画面上の名称
- 入力種別：テキスト、ボタン、リンク、ラベル、プルダウンなど
- 入力文字タイプ：全角、半角英数字、数値、記号など
- 桁数：入力可能な最大桁数
- 必須：入力必須かどうか　〇：必須
- 初期値（設定値）：入力項目に表示する初期値
- プレースホルダー：未入力時に表示する入力例や説明文
- 活性／非活性：利用可能条件　**※空は常に活性状態**
- 表示条件：表示条件がある場合のみ記載 **※空は常に表示**
- 説明：項目の用途や役割

---

#### 備考
※日付・時間はDatePicker、Time Pickerのようなものを想定。
https://mui.com/x/react-date-pickers/time-picker/

+ レッスン可能な日付と時間（範囲指定）を選択する。
 　↓
+ 公開すると、空き枠選択画面にその範囲が30分単位で○が表示される。 


#### イベント定義

##### 初期表示時
- 講師名（姓）・コースドロップダウンリストの設定
  - 講師名（姓）および担当するコースをDBから取得する。
  - ドロップダウンリストに設定する。
  - 利用者が講師の場合は、ログイン中の講師を選択状態にする。
  - 利用者がスタッフの場合は、1行目の「選択してください」を選択状態にする。

##### 登録内容を確認ボタンを押下時
- レッスン枠登録確認画面へ遷移する。入力・選択した講師名・コース、開始日時・時間、終了日時・時間を次画面へ渡す。（補足参照）　 

#### 補足
#####　ドロップダウンリストの設定値

**講師名・コース**
講師名（姓）と担当するコースを以下のように表示する
（例）
|行数|設定値|
|---|---|
|1|選択してください|
|2|櫻井（ギター）|
|3|二宮（ギター）|
|4|二宮（ピアノ）|
|5|松本（ボーカル）|

#### バリデーション

|対象項目|チェック内容|
|---|---|
|講師名・コース|1.必須チェック|
|日付|1.必須チェック|
|開始時間|1.必須チェック|
|終了時間|1.必須チェック|

#####　関連チェック
|対象項目|チェック内容|エラーメッセージ|
|---|---|---|
|開始時間・終了時間|開始時間 < 終了時間であること|開始時間より後の終了時間を入力してください。|

**補足**
次画面への遷移はReact Routerの利用を想定。
useNavigateのstateに値を設定する。

```
navigate("/lesson-schedule-confirm", {
state: {
      teacherId: 1,
      teacherName: "二宮",
      course: "ピアノ",
      StartDateTime: "2026-09-01T10:00:00",
      EndDateTime: "2026-09-01T13:00:00"
  }
});
```
