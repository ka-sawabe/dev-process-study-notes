# 画面項目定義

---
## <凡例>　各項目の意味
### 画面項目

- 項目ID：項目を一意に識別するID
- 項目名：画面上の名称
- 入力種別：テキスト、ボタン、リンク、ラベル、プルダウンなど
- 入力文字タイプ：全角、半角英数字、数値、記号など
- 桁数：入力可能な最大桁数
- 必須：入力必須かどうか　〇：必須
- 初期値（設定値）：入力項目に表示する初期値
- プレースホルダー：未入力時に表示する入力例や説明文
- 活性／非活性：利用可能条件　**※空は常に活性状態**
- 表示条件：表示条件がある場合のみ記載 **※空は常に表示**
- 説明：項目の用途や役割

##### 補足

**利用者区分の表示について**
遷移元の違いによって表示分けをする。
- ☆1[ログイン画面⇒ユーザー登録画面⇒ユーザー登録確認画面]　で遷移した場合
- ☆2[招待メールのURL⇒利用者区分選択画面⇒ユーザー登録画面⇒ユーザー登録確認画面]　で遷移した場合

---

#### イベント定義

##### 初期表示時
- 以下を前画面から受け取って、ラベルに設定する。
  - 遷移元の画面名
  - 利用者区分
  - 氏名（姓・名）、メールアドレス、パスワード、電話番号
  - 講師名・コース（利用者区分が生徒の場合）／選択したすべてのコース（利用者区分が講師の場合） 

##### 登録するボタン押下時
- 登録処理を実行する。
  - DBにユーザー情報を登録する。
- ユーザー登録完了画面へ遷移する。
- 以下を次画面に渡す。（補足参照）
  - 氏名（姓・名）、メールアドレス、パスワード、電話番号
  - 処理結果（登録成功／登録失敗）

##### 戻るボタン押下時
- ユーザー登録画面へ遷移する。

#### バリデーション

なし

**補足**
次画面への遷移はReact Routerの利用を想定。
useNavigateのstateに値を設定する。

例
```
navigate("/lesson-schedule-result", {
state: {
      user:{
        userFirstName: "山田",
        userLastName: "涼介",
        mail:"test@test.co.jp",
        password:"pass1234",
        telephone:"12345678901",
      },
      success:true   
  }
});
```
