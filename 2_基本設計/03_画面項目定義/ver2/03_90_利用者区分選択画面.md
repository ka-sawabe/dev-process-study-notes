# 画面項目定義

---
## <凡例>　各項目の意味
### 画面項目

- 項目ID：項目を一意に識別するID
- 項目名：画面上の名称
- 入力種別：テキスト、ボタン、リンク、ラベル、プルダウンなど
- 入力文字タイプ：全角、半角英数字、数値、記号など
- 桁数：入力可能な最大桁数
- 必須：入力必須かどうか　〇：必須
- 初期値（設定値）：画面表示時の初期値
- プレースホルダー：未入力時に表示する入力例や説明文
- 活性／非活性：利用可能条件　**※空は常に活性状態**
- 表示条件：表示条件がある場合のみ記載 **※空は常に表示**
- 説明：項目の用途や役割

## G090 利用者区分選択画面
---

※招待メールのURLから遷移した場合のみ表示する。


### 画面項目定義

|項目ID|項目名|入力種別|入力文字タイプ|桁数|必須|初期値（設定値）|プレースホルダー|活性／非活性|表示条件|説明|
|---|---|---|---|---|---|---|---|---|---|---|
|I0010|利用者区分|ラジオボタン|－|－|〇|生徒|－|||利用者区分を選択する。<br>形式：○生徒 ○講師 ○スタッフ|
|I0020|次へ|ボタン|－|－|－|－|－||||ユーザー登録画面へ遷移する。|

#### イベント定義

##### 次へ押下時
- ユーザー登録画面へ遷移する。
- 選択した値を次画面に渡す（補足参照）
  - 遷移元の画面名
  - 利用者区分

#### バリデーション

なし

---
**補足**
次画面への遷移はReact Routerの利用を想定。
useNavigateのstateに値を設定する。

例
```
navigate("/user-register", {
state: {
      source : "invitation",
      userCategory:2,     
}
});
```
