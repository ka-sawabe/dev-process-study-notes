# 画面項目定義

---
## <凡例>　各項目の意味
### 画面項目

- 項目ID：項目を一意に識別するID
- 項目名：画面上の名称
- 入力種別：テキスト、ボタン、リンク、ラベル、プルダウンなど
- 入力文字タイプ：全角、半角英数字、数値、記号など
- 桁数：入力可能な最大桁数
- 必須：入力必須かどうか　〇：必須
- 初期値（設定値）：画面表示時の初期値
- プレースホルダー：未入力時に表示する入力例や説明文
- 活性／非活性：利用可能条件　**※空は常に活性状態**
- 表示条件：表示条件がある場合のみ記載 **※空は常に表示**
- 説明：項目の用途や役割

## G020 講師・生徒選択画面
---

※講師・スタッフがログインした場合のみ表示する。

### 画面項目定義

|項目ID|項目名|入力種別|入力文字タイプ|桁数|必須|初期値（設定値）|プレースホルダー|活性／非活性|表示条件|説明|
|---|---|---|---|---|---|---|---|---|---|---|
|I0010|講師名・コース|検索可能なドロップダウンリスト|-|-|〇|利用者が<br>講師の場合：ログイン中の講師名を選択<br>スタッフの場合：未選択|-||| 講師名（姓）+ その講師が担当するコースをリストに表示する。形式：{講師名}({コース})<br>講師とコースを選択する。|
|I0020|生徒名|検索可能なドロップダウンリスト|-|-|〇|未選択|-|講師名・コースが<br>未選択の場合：非活性<br>選択済みの場合：活性||上記で選択した講師が担当する生徒名をリストに表示する。形式：生徒名（姓）+ 全角スペース + 生徒名（名）<br>生徒を選択する。|
|I0030|次へ|ボタン|－|－|－|－|－|||空き枠選択画面に遷移する。|
|I0040|レッスン枠登録画面リンク|リンク|－|－|－|－|－|||レッスン枠登録画面へ遷移する。|

#### 補足
#####　ドロップダウンリストの設定値

**講師名・コース**
講師名（姓）と担当するコースを以下のように表示する
（例）
|行数|設定値|
|---|---|
|1|選択してください|
|2|櫻井（ギター）|
|3|二宮（ギター）|
|4|二宮（ピアノ）|
|5|松本（ボーカル）|

**生徒名**
生徒名を以下のように表示する
（例）
|行数|設定値|
|---|---|
|1|選択してください|
|2|相葉　雅紀|
|3|菊池　風磨|
|4|山田　涼介|

#### イベント定義

##### 初期表示時
- 講師名（姓）・コースドロップダウンリストの設定
  - 講師名（姓）および担当コースをDBから取得する。
  - ドロップダウンリストに設定する。
  - 利用者が講師の場合は、ログイン中の講師を選択状態にする。
  - 利用者がスタッフの場合は、1行目の「選択してください」を選択状態にする。

- 生徒名ドロップダウンリストの設定
  - 「選択してください」のみドロップダウンリストに設定する。
  - 1行目の「選択してください」を選択状態にする。

##### 講師名（姓）・コースの選択値の変更時
- 生徒名ドロップダウンリストの設定
  - 選択した講師・コースに紐づく生徒の一覧を取得し、 ドロップダウンリストに設定する。
  - 1行目の「選択してください」を選択状態にする。

##### 次へ押下時
- 空き枠選択画面へ遷移する。選択した生徒名、講師名・コースを次画面へ渡す。（補足参照）

##### レッスン枠登録画面リンク
- レッスン枠登録画面へ遷移する。

#### バリデーション

|対象項目|チェック内容|
|---|---|
|講師名・コース|2.必須チェック(未選択)|
|生徒名|2.必須チェック(未選択)|


---
**補足**
次画面への遷移はReact Routerの利用を想定。
useNavigateのstateに値を設定する。

例
```
navigate("/lesson-select", {
state: {
      selectedStudent: {
      studentId: 10,
      studentName: "山田 涼介"
    },
    selectedTeacher: {
      teacherId: 1,
      teacherName: "山田",
      course: "ピアノ"
    }
  }
});
```
