# STEP7 CRUD

## CRUDとは
CRUDとは、
- Create（登録）
- Read（参照）
- Update（更新）
- Delete（削除）
の頭文字です。CRUDとは、機能ごとにどのテーブルを
- 登録するのか
- 参照するのか
- 更新するのか
- 削除するのか
を整理する成果物です。

---
## 作成目的
機能とテーブルの関係を整理することです。
後続の
- 詳細設計
- 実装
のインプットとなります。

## CRUDの形式
今回の学習では以下の形式を採用します。
| 画面        | 商品  | 商品詳細  | 注文 | 注文詳細  | カテゴリ | メーカー  |
| ----------- | ---- | -------- | ---- | -------- | -------- | -------- |
| 商品検索画面 | R    |          |      |          |          |          |
| 商品詳細画面 | R    | R        |      |          | R        | R        |
| 注文確認画面 | R    |          | C    | C        |          |          |
| 注文完了画面 |      | R        | R    | R        |          |          |

---
## 項目の意味
- C：Create（登録）
- R：Read（参照）
- U：Update（更新）
- D：Delete（削除）
該当するものを記載します。

---
## なぜ必要なのか
ER図だけでは、
どの機能が
どのテーブルを利用するのか
分かりません。
例えば、
ユーザー登録機能があった場合、
ユーザー情報を登録することは分かりますが、
- どのテーブルへ登録するのか
- どのテーブルを参照するのか
- どのテーブルを更新するのか
までは分かりません。
そのため、
機能とテーブルの利用関係を整理するためにCRUDを作成します。

---
## ER図との違い
### ER図
テーブル同士の関係を整理する。
例
```text
カテゴリ
↓
商品
↓
商品詳細
↓
メーカー

商品
↓
注文詳細
↓
注文
```


---
### CRUD
機能とテーブルの関係を整理する。
例
```text
商品詳細画面
商品 → R
商品詳細 → R
カテゴリ → R
メーカー → R
```

---
## ポイント

### どうやって作るのか

#### １、機能一覧または画面一覧を見る
まず対象機能を確認します。
例
- 商品検索画面
- 商品詳細画面
- 注文確認画面
- 注文完了画面
 
---
#### ２、画面項目定義を見る
各機能で何を表示し、何を登録するのか確認します。
例
###### 商品検索画面
- 商品名
- カテゴリ
- 商品一覧
###### 商品詳細画面
- 商品名
- カテゴリ
- 価格
- 商品説明
- メーカー
###### 注文確認画面
- 商品名
- カテゴリ
- 価格
- 数量
- 購入金額
###### 注文完了画面
- 商品名
- 購入金額

---
#### ３、利用するテーブルを確認する
例
- 商品検索：商品テーブル
- 商品詳細画面：商品テーブル、商品詳細テーブル、カテゴリテーブル、メーカーテーブル
- 注文確認画面：商品テーブル、注文テーブル、注文詳細テーブル
- 注文完了画面：商品テーブル、注文テーブル、注文詳細テーブル
---
#### ４、CRUDを判定する

例
##### 商品検索画面
- 商品情報を取得して表示する。⇒商品テーブル：R

##### 商品詳細画面
- 商品情報を取得して表示する。⇒商品テーブル、商品詳細テーブル、カテゴリテーブル、メーカーテーブル：R

##### 注文確認画面
- 商品情報を取得して表示する。⇒商品テーブル：R
- 注文情報を登録する。⇒注文テーブル：C
- 注文した商品情報を登録する。⇒注文詳細テーブル：C

##### 注文完了画面
- 注文結果を表示する。⇒商品テーブル、注文テーブル、注文詳細テーブル：R

## レビュー観点
### ① 機能漏れがないか
すべての機能がCRUDに記載されているか。

### ② テーブル漏れがないか
利用するテーブルがすべて記載されているか。

### ③ CRUD判定が正しいか
- Create
- Read
- Update
- Delete
のどれなのか。

#### ④ ER図と整合しているか
存在しないテーブルを利用していないか。

#### ⑤ 業務ルールと整合しているか
必要な登録・参照・更新・削除ができるか。

---
### この成果物で理解すること
CRUDを作成することで、
- どの機能が
- どのテーブルを
- どのように利用するのか
を整理できます。
CRUDとは、
機能とテーブルの関係を整理し、
システム全体のデータの流れを把握するための成果物です。
