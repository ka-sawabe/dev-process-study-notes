## パスパラメータとクエリパラメータ
URLパラメータにはパスパラメータとクエリパラメータがある

### パスパラメータ
：URLの一部を変数として受け取る
　一般的には対象そのものを指定するのに使用する

　/items/42にアクセスすると{"item_id": 42}が返る

### クエリパラメータ
：URLの?以降に指定するパラメータ
　検索条件・絞り込み条件に使用する

　複数の場合は&でつなぐ。
　https://example.com/pokemon?id=25&name=pikachu

　Reactだと
　fetch("/pokemon?id=25")
　になります。

※IF定義に記載するパラメータは両方を指す。

# HTTPリクエスト / レスポンスの仕組み

HTTP通信には4つの登場人物がいる

## リクエスト
URL
ヘッダ
パラメータ
ボディ

## レスポンス
ヘッダ
ボディ


### GETの場合
#### イメージ

GET / pokemon ? id = 25
「25番のポケモンください」

#### パラメータ

パスパラメータもしくはクエリパラメータを指定する

#### リクエストヘッダ

裏で送る情報

例えば
Authorization: Bearer xxxxx
Content - Type: application / json
など。

##### よくある例
fetch("/pokemon?id=25", {
  headers: {
    Authorization: "Bearer abc123"
  }
})

#### リクエストボディ

GETは基本的に使わない。

つまり

GET
↓
パラメータで指定
↓
ボディなし

です。

初心者はまず
GET = ボディなし
と思ってOK。

#### レスポンスヘッダ

サーバーから返る説明書

例えば
Content - Type: application / json
Status: 200
とか。

##### レスポンスボディ

本当に欲しいデータ。

例
{
  "id": 25,
    "name": "pikachu"
}

これをReactで使います。

##### GETを図にすると

** React **
GET / pokemon ? id = 25
↓
【リクエスト】
- URL： /pokemon
- パラメータ：あり(パラメータが付くことが多い) ? id = 25
- リクエストヘッダ：あり Authorization: Bearer xxxx
- リクエストボディ：なし
 
────────── 
** Server **
【レスポンス】 
↓
- ステータスコード：あり 200 OK
- レスポンスヘッダ：あり Content - Type: application / json
- レスポンスボディ：あり  { "id": 25, "name": "pikachu" }

### POSTの場合

POSTはデータを登録したいときに使う。

例えば会員登録
  - 名前
  - メール
  - パスワード
を送る。

#### パラメータ
POSTでも付けられる。
/users?type=normal

ただあまり使われない。

#### リクエストヘッダ
GETと同じ。
例
Content - Type: application / json


#### リクエストボディ

POSTの主役。
{
  "name": "山田",
    "mail": "aaa@test.com"
}

##### fetchの例
fetch("/users", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    name: "山田",
    mail: "aaa@test.com"
  })
})


#### レスポンスボディ

登録結果が返る。
{
  "id": 100,
    "name": "山田"
}

#### POSTを図にする
** React **
POST / users
【リクエスト】
- URL： /users
- パラメータ：なし（使えるけど、あまり使われない）
- リクエストヘッダ：あり（必要なら付ける）
  - Content - Type: application / json
  - Authorization: Bearer xxxx
- リクエストボディ：あり（通常あり）
  -  { "name": "山田", "mail": "aaa@test.com" } 
──────────
** Server **
【レスポンス】
- ステータスコード：あり 200 OK
- レスポンスヘッダ：あり Content - Type: application / json
- レスポンスボディ：あり
   - { "id": 100, "name": "山田" }

## GETの例

```typescript
import { useQuery } from "@tanstack/react-query";

// ポケモン詳細取得
export const PokemonDetail = ({ pokemonId }: { pokemonId: number }) => {
    const {
        data, // レスポンスボディがここに入る
        isLoading, // 通信中かどうか
        isError, // エラーになったかどうか
    } = useQuery({

        // TanStack Queryのキャッシュキー
        // pokemonId が変わると別データとして管理される
        queryKey: ["pokemonDetail", pokemonId],

        // API取得処理
        queryFn: async () => {

            // =========================
            // HTTPリクエスト
            // =========================

            const response = await fetch(
              　//パスパラメータに指定
                `https://pokeapi.co/api/v2/pokemon/${pokemonId}`,

                // fetchの第2引数には
                // リクエストヘッダなどを設定できる
                {
                    headers: {
                        Authorization: "Bearer xxxx",
                    },
                }
            );

            // この時点のHTTPイメージ
            //
            // GET /pokemon/25
            //
            // 【リクエスト】
            // URL（パスパラメータに25を指定）
            // /pokemon/25
            // 
            // パスパラメータ
            // pokemonId = 25
            // クエリパラメータ
            // なし
            //
            // リクエストヘッダ
            // Authorization: Bearer xxxx
            //
            // リクエストボディ
            // なし

            // =========================
            // HTTPレスポンス確認
            // =========================

            console.log(response.status);
            // 例
            // 200
            // 404
            // 500

            console.log(
                response.headers.get("content-type")
            );
            // 例
            // application/json

            // エラーなら例外発生
            if (!response.ok) {
                throw new Error("取得失敗");
            }

            // =========================
            // レスポンスボディ取得
            // =========================

            const data = await response.json();

            // data の中身のイメージ
            //
            // {
            // "id": 25,
            // "name": "pikachu"
            // }

            return data;
        },
    });

    // TanStack Query が管理してくれる

    if (isLoading) {
        // API通信中
        return <div>読み込み中...</div>;
    }

    if (isError) {
        // APIエラー
        return <div>エラーが発生しました </div>;
    }

    // data は response.json() の結果
    return (
        <div>
            <h2>{data.name} </h2>
            < p > ID: {data.id} </>
        </div>
    );
};
```
