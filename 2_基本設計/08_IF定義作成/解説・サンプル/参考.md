# HTTPリクエスト / レスポンスの仕組み

HTTP通信には以下の登場人物がいる

#### リクエスト
 
① URL
② パラメータ
├─ パスパラメータ
└─ クエリパラメータ
③ リクエストヘッダ
④ リクエストボディ
 
↓
 
#### レスポンス 
⑤ ステータスコード
⑥ レスポンスヘッダ
⑦ レスポンスボディ

---

## パスパラメータとクエリパラメータ
URLパラメータにはパスパラメータとクエリパラメータがある

### パスパラメータ
：URLの一部を変数として受け取る
　一般的には対象そのものを指定するのに使用する

　/items/42にアクセスすると{"item_id": 42}が返る

### クエリパラメータ
：URLの?以降に指定するパラメータ
　検索条件・絞り込み条件に使用する

　複数の場合は&でつなぐ。
　https://example.com/pokemon?id=25&name=pikachu

※IF定義に記載するパラメータはパスパラメータとクエリパラメータの両方を指す。

---

### GETの場合
#### イメージ
GET 
URL:`https://pokeapi.co/api/v2/pokemon/${pokemonId}`,
「25番のポケモンください」

---
#### リクエスト
##### パラメータ
パスパラメータもしくはクエリパラメータを指定する

※パスパラメータを使用する例
URL:`https://pokeapi.co/api/v2/pokemon/${pokemonId}`,
 パスパラメータ pokemonId = 25

##### リクエストヘッダ
裏で送る情報

例
- Authorization: Bearer xxxxx
※認証が必要なAPIな場合にAuthorization を付与
- Accept: application/json
※返してもらうデータの形式を指定する。上の例だと「JSONを返してください」という意味。

##### リクエストボディ
GETでは基本的に使わない。

---
#### レスポンス
##### ステータスコード
成功したかどうか
200 など

##### レスポンスヘッダ
サーバーから返る説明書

例
Content - Type: application / json
※Content-Typeはデータの形式。（サーバーから送られるデータ）


##### レスポンスボディ

サーバーから送られるデータ。
これをフロント側で使う。
例
{"id": 25,"name": "pikachu"}

---
### POSTの場合

POSTはデータを登録したいときに使う。

例えば会員登録
  - 名前
  - メール
  - パスワード
を送る。

---
#### リクエスト

#### パラメータ
パラメータはPOSTでも付けられるが、基本的にはあまり使わない。
例
/users?type=normal

#### リクエストヘッダ
裏で送る情報

例
- Authorization: Bearer xxxxx
※認証が必要なAPIな場合にAuthorization を付与
- Content - Type: application / json
※Content-Typeはデータの形式。（POSTの場合フロントからサーバーへ送るデータ）

#### リクエストボディ

フロントからサーバーへ送るデータ
例
{"name": "山田","mail": "aaa@test.com"}

---
#### レスポンス
##### ステータスコード

200 など

##### レスポンスヘッダ
サーバーから返る説明書

例
Content - Type: application / json
※Content-Typeはデータの形式。（サーバーから送られるデータ）

##### レスポンスボディ
登録結果が返る。
{"id": 100,"name": "山田"}

##### fetchの例
```typescript
fetch("/users", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    name: "山田",
    mail: "aaa@test.com"
  })
})
```

##### ＜＜GET＞＞

**React**
GET URL：/pokemon/{pokemonId}
↓
【リクエスト】
- URL： /pokemon
- パラメータ：あり(パラメータが付くことが多い。例えば取得条件はここに書く。)
  -  パスパラメータ pokemonId = 25
- リクエストヘッダ：あり（必要な場合付ける）
  - Authorization: Bearer xxxxx　
      ※認証が必要なAPIなら Authorization を付与
  - Accept: application/json
　　　※返してもらうデータの形式を指定する。
- リクエストボディ：なし
 
────────── 
**Server**
【レスポンス】
- ステータスコード：あり 200 OK
- レスポンスヘッダ：あり
  - Content - Type: application / json
- レスポンスボディ：あり  { "id": 25, "name": "pikachu" }
  
---
#### ＜＜POST＞＞
**React**
  POST / users
【リクエスト】
- URL： /users
- パラメータ：なし（概念的にはあるけど、通常使わない設計のAPIが多い）
- リクエストヘッダ：あり（必要なら付ける）
  - Content - Type: application / json　
      ※Content-Typeは送るデータの形式。
  - Authorization: Bearer xxxx
- リクエストボディ：あり（通常あり。例えば登録内容などはパラメータではなくここに書く。）
  -  { "name": "山田", "mail": "aaa@test.com" } 
──────────
**Server**
【レスポンス】
- ステータスコード：あり 200 OK
- レスポンスヘッダ：あり 
  - Content - Type: application / json
- レスポンスボディ：あり
  - { "id": 100, "name": "山田" }

## IF001 ポケモン詳細取得
 
### 基本情報
 
|項目|内容|
|---|---|
|IFID|IF001|
|IF名|ポケモン詳細取得|
|FROM|ポケモン詳細画面|
|TO|ポケモン詳細取得API|
|タイミング|画面初期表示時|
|プロトコル|HTTPS(GET)|
|データ形式|JSON|
|要求URI|/pokemon/{pokemonId}|
 
---
 
### リクエスト
  
#### パラメータ
 
|No|項目名|データ型|桁数|必須|説明|
|---|---|---|---|---|---|
|1|pokemonId|number|10|○|取得対象のポケモンID| 

#### リクエストヘッダ

なし
  
#### リクエストボディ
 
なし
 
---
 
### レスポンス
 
#### ステータスコード
 
|コード|説明|
|---|---|
|200|正常終了|
|404|ポケモンが存在しない|
|500|サーバーエラー|
 
#### レスポンスヘッダ
 
|No|項目名|値|
|---|---|---|
|1|Content-Type|application/json|
 
#### レスポンスボディ
 
|No|項目名|データ型|桁数|必須|説明|
|---|---|---|---|---|---|
|1|id|number|10|○|ポケモンID|
|2|name|string|100|○|ポケモン名|
|3|height|number|10|○|高さ|
|4|weight|number|10|○|重さ|

### コード

```typescript
import { useQuery } from "@tanstack/react-query";

// ポケモン詳細取得
export const PokemonDetail = ({ pokemonId }: { pokemonId: number }) => {
    const {
        data, // レスポンスボディがここに入る
        isLoading, // 通信中かどうか
        isError, // エラーになったかどうか
    } = useQuery({

        // TanStack Queryのキャッシュキー
        // pokemonId が変わると別データとして管理される
        queryKey: ["pokemonDetail", pokemonId],

        // API取得処理
        queryFn: async () => {

            // =========================
            // HTTPリクエスト
            // =========================

            const response = await fetch(
              　//パスパラメータに指定
                `https://pokeapi.co/api/v2/pokemon/${pokemonId}`,

                // fetchの第2引数には
                // リクエストヘッダなどを設定できる　ポケAPIでは使わない
                //{
                //    headers: {
                //        Authorization: "Bearer xxxx",
                //    },
                //}
            );

            // この時点のHTTPイメージ
            //
            // GET /pokemon/25
            //
            // 【リクエスト】
            // URL（パスパラメータに25を指定）
            // /pokemon/25
            // 
            // パスパラメータ
            // pokemonId = 25
            // クエリパラメータ
            // なし
            //
            // リクエストヘッダ
            // なし
            //
            // リクエストボディ
            // なし

            // =========================
            // HTTPレスポンス確認
            // =========================

            console.log(response.status);
            // ステータスコード
            // 200
            // 404
            // 500

            console.log(
                response.headers.get("content-type")
            );
            // レスポンスヘッダ
            // application/json

            // エラーなら例外発生
            if (!response.ok) {
                throw new Error("取得失敗");
            }

            // =========================
            // レスポンスボディ取得
            // =========================

            const data = await response.json();

            // data の中身のイメージ
            //
            // {
            // "id": 25,
            // "name": "pikachu"
            // }

            return data;
        },
    });

    // TanStack Query が管理してくれる

    if (isLoading) {
        // API通信中
        return <div>読み込み中...</div>;
    }

    if (isError) {
        // APIエラー
        return <div>エラーが発生しました </div>;
    }

    // data は response.json() の結果
    return (
        <div>
            <h2>{data.name} </h2>
            < p > ID: {data.id} </>
        </div>
    );
};
```
