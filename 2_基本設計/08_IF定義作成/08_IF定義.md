# IF定義

## IF001 ログイン認証

### 基本情報
| 項目       | 内容                 |
| ---------- | -------------------- |
| IFID       | IF001                |
| IF名       | ログイン認証         |
| FROM       | ログイン画面         |
| TO         | ログイン認証API      |
| タイミング | ログインボタン押下時 |
| プロトコル | HTTPS(POST)           |
| データ形式 | JSON                 |
| 要求URI    | /login               |

---
### リクエスト
#### URL
```text
/login
```
#### パラメータ
なし
#### リクエストヘッダ
| No  | 項目名       | 必須 | 値               | 備考   |
| --- | ------------ | ---- | ---------------- | ------ |
| 1   | Content-Type | ○    | application/json | 固定値 |
| 2   | Accept       | ○    | application/json | 固定値 |
#### リクエストボディ
| No  | 項目名     | データ型 | 桁数 | 必須 | 説明                   |
| --- | ---------- | -------- | ---- | ---- | ---------------------- |
| 1   | ユーザーID | string   | 256  | ○    | メールアドレスを使用 |
| 2   | パスワード | string   | 128  | ○    | パスワード             |
 
{
"userId": "test@test.co.jp",
"password": "password123"
}

### レスポンス
#### ステータスコード
| コード | 説明     |
| ------ | -------- |
| 200    | 正常終了 |
#### レスポンスヘッダ
| No  | 項目名       | 値               |
| --- | ------------ | ---------------- |
| 1   | Content-Type | application/json |
#### レスポンスボディ
| No  | 項目名     | データ型 | 桁数 | 必須 | 説明 |
| --- | ---------- | -------- | ---- | ---- | --- |
| 1   | トークン   | string   | 512  | ○    | 認証が成功したらサーバーから発行する値 |
| 2   | 利用者区分 | string   | 1    | ○    | 本アプリの利用者区分                   |


{
    "token": "abc123xyz",
    "userCategory": "1"
}


---

### 作成メモ

---

POST /login

**React**
- URL：/login
- パラメータ：なし
- リクエストヘッダ
 - Content-Type: application/json
    ※送るデータはJSON形式
 - Accept: application/json
    ※JSON形式で返してほしい
- リクエストボディ
    ID・パスワードを送る
        {
            "userId": "test@test.co.jp",
            "password": "password123"
        }
---
**Server**
tokenを取得して返す。
- ステータスコード：200 OK
- レスポンスヘッダ
- Content-Type: application/json
- レスポンスボディ
        {
            "token": "abc123xyz",
            "userCategory": "1"
        }

---
