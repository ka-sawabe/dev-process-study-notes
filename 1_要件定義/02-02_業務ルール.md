## STEP2-2 業務ルール を作成

# 業務ルール一覧
 
| ID | 業務ルール | 
|------|------|
| R001 | 生徒は入会時に楽器コースを選択する。 |
| R002 | 生徒ごとに担当講師が固定で割り当てられ、生徒は担当講師を選択できない。レッスンが予約できるのは担当講師の枠のみとする。 |
| R003 | レッスンは個人レッスン形式とする。1回30分、月4回まで受講可能とし、未受講分の翌月への繰り越しはできない。（例：当月4回受講済みなら次の予約は翌月の枠とする。） |
| R004 | レッスン受講後に次回レッスンを予約する。 |
| R005 | 講師は通常4週間前までにレッスン枠を共有する。ただし、講師の都合が合えば随時レッスン枠を追加できる。（例：予約受付時にGoogleカレンダーに希望日の空きがない場合でも、講師の都合が合えばレッスン枠を追加登録し、そのまま予約することができる。） |
| R006 | 予約受付は対面、電話、メールで行う。 |
| R007 | 予約情報はGoogleカレンダー、受講回数はスプレッドシートで管理する。 |
| R008 | 希望日時に空きがない場合は別候補日を提示する。 |
