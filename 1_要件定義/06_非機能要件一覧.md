# 非機能要件一覧

| 区分 | 要件 |
|--------|--------|
| 利用環境 | 生徒、講師・スタッフはPCおよびスマートフォンからシステムを利用できること。 |
| 認証 | 利用者はログイン後にシステムを利用できること。 |
| 可用性 | システムは24時間利用可能とする。ただしメンテナンス時間を除く。 |
| 性能 | 主要画面は3秒以内に表示されること。 |
| バックアップ | 予約情報およびレッスン枠情報を定期的にバックアップすること。 |
| 権限管理 | 生徒、講師・スタッフごとに利用可能な機能を制御すること。 |
| 通知 | 予約完了時に生徒および講師へ通知すること。 |
| セキュリティ | 通信は暗号化すること。 |
